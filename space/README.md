# Peta IDW · Stasiun Klimatologi Papua Barat

Web page for the Create-Map-IDW package: upload the data files, check the maps
detected from them, pick the wilayah, run and download the maps.

Secrets (Space settings → Variables and secrets): `GEMINI_API_KEY`, `GITHUB_TOKEN`.

Source of these files: `space/` in https://github.com/nashathur/Create-Map-IDW;
design in `docs/hf-space-plan.md` there.
